# Пользовательские сценарии

## 1. Создание закупки

```
Группа: закреплённое сообщение «🛒 Совместные покупки»
        [➕ Создать совместную покупку]  →  t.me/<bot>?start=create
   или  /buy  →  бот отвечает редиректом в личку
                          │
                          ▼
Личка: 📜 Правила  [📄 Читать] [✅ Принимаю] [❌ Отмена]
                          │ принял
                          ▼
Мастер, 10 шагов:
  1. Название товара
  2. Ссылка на товар            (можно пропустить)
  3. Фото                       (можно пропустить, сохраняем file_id)
  4. Цена за единицу
  5. Валюта                     (кнопки EUR / USD / BGN)
  6. Допустимые варианты        (можно пропустить)
  7. Сколько берёт организатор  (проверяется лимит)
  8. Дата окончания сбора
  9. Место получения
 10. Комментарий                (можно пропустить)
                          │
                          ▼
Предпросмотр  [✅ Опубликовать] [✏️ Изменить] [❌ Отмена]
                          │ опубликовать
                          ▼
Объявление в группе от имени бота + кнопки [🛒 Присоединиться] [📜 Правила]
Организатору — панель управления
```

«✏️ Изменить» открывает список полей: правится одно поле и пользователь
возвращается в предпросмотр.

## 2. Присоединение

```
Группа: [🛒 Присоединиться]  →  t.me/<bot>?start=join_<public_token>
                          │
                          ▼
Личка: карточка закупки
  • закупки нет / отменена / закрыта / дедлайн истёк → сообщение и стоп
  • пользователь — организатор → панель организатора
  • уже участвует → карточка своей заявки
                          │ иначе
                          ▼
📜 Правила (если версия не принята)  →  ✅ Принимаю
                          │
                          ▼
Форма:
  1. Количество   → сразу проверяется лимит €150
  2. Вариант      (можно пропустить)
  3. Комментарий  (можно пропустить)
                          │
                          ▼
Предпросмотр  [✅ Подтвердить] [✏️ Изменить] [❌ Отмена]
                          │ подтвердить
                          ▼
Заявка сохранена  →  объявление в группе обновлено
                  →  организатору личное уведомление
                  →  участнику карточка [✏️ Изменить] [❌ Отказаться] [📦 Мои покупки]
```

### Что происходит при превышении лимита

```
⚠️ После добавления закупка превысит лимит €150,00.

Сейчас собрано: €142,00
Вы хотите добавить: €12,00
Итого получилось бы: €154,00

Максимально можно добавить: 4 шт.
Введите другое количество.
```

Заявка не сохраняется, шаг повторяется.

## 3. Изменение и отказ

Пока сбор открыт, участник может поменять количество, вариант, комментарий
или отказаться. После каждого изменения бот пересчитывает закупку и
перерисовывает объявление в группе. При изменении количества лимит
проверяется заново, причём собственный текущий вклад из суммы вычитается —
иначе нельзя было бы даже уменьшить заявку.

## 4. Панель организатора

```
🛠 Совместная покупка #42
Статус: 🟢 Сбор открыт
👥 Участников: 8   📦 Товаров: 13   💰 €72,40 из €150,00

[👥 Участники] [✏️ Изменить закупку] [🔒 Закрыть сбор] [❌ Отменить закупку]
```

- **Участники** — список с количеством, вариантом, комментарием и суммой.
  Если у участника нет username, организатор видит имя и Telegram ID.
  В группу эти данные не попадают.
- **Изменить закупку** — правка любого поля, кроме валюты. Смена цены
  запрещена, если новая цена выводит закупку за лимит.
- **Закрыть сбор** — с подтверждением. Кнопка «Присоединиться» исчезает,
  объявление помечается «🔒 СБОР ЗАКРЫТ», участники получают личное сообщение.
- **Отменить закупку** — с подтверждением, объявление помечается отменённым.


Кнопки открывают панель организатора или карточку своей заявки.

## 6. Автозакрытие по дедлайну

Раз в `DEADLINE_CHECK_INTERVAL_SECONDS` (по умолчанию 5 минут) и один раз при
старте бот находит открытые закупки с истёкшим сроком, переводит их в `CLOSED`,
обновляет объявление и уведомляет участников и организатора.

## 7. Команды

| Команда | Где | Кто | Что делает |
|---------|-----|-----|-----------|
| `/start` | личка | все | главное меню |
| `/start create` | личка | все | создание закупки (deep link) |
| `/start join_<token>` | личка | все | присоединение (deep link) |
| `/buy` | личка | все | создание закупки |
| `/buy` | группа | все | редирект в личку |
| `/my` | личка | все | мои покупки |
| `/menu` | личка | все | главное меню |
| `/cancel` | личка | все | прервать текущий диалог |
| `/setup` | группа | админ | опубликовать сообщение для закрепления |
| `/chatid` | группа | админ | показать ID чата |
| `/stats` | личка | админ | статистика сервиса |
| `/purchases` | личка | админ | последние закупки |
